# ACE Medias Tools INES

INES is a professional call‑management solution designed for radio and television environments, enabling studios to efficiently handle live callers across RTC/PSTN, ISDN, VoIP, AoIP, and WebRTC connections. It provides a centralized interface for managing call queues, controlling telephone inserts and codecs, and coordinating on‑air interactions, making it ideal for talk shows and audience‑driven broadcasts. The system also supports integration with social platforms and maintains caller information to streamline workflows and enhance real‑time audience engagement.

## Key Capabilities

- **Real-time line monitoring**: Track the operational status of every codec line — connection state, audio presence, mute status, and call direction — at a 10-second polling interval.
- **Call control**: Start and stop calls on any line directly from DataMiner, with an operator confirmation step before execution.
- **Call direction awareness**: Distinguish between idle, incoming, and outgoing calls per line to support on-air coordination workflows.
- **Remote endpoint visibility**: See the IP address or hostname of the connected remote party for every active call.
- **Codec capability management**: View and update each line's audio protocol configuration, including codec type (AES67, G.711, MPEG, and others), transport (RTP, UDP, TCP), data rate, channel count, and sampling rate.
- **SIP integration**: Displays the SIP registrar server associated with each line's SIP account for topology awareness.
