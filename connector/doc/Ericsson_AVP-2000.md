# Ericsson AVP-2000

The **Ericsson AVP-2000** connector integrates the Ericsson AVP-2000 Advanced Video Processor into DataMiner over HTTP, giving you a single interface to monitor and manage the device.

## About

The Ericsson AVP-2000 is an **Advanced Video Processor** used in video contribution and distribution workflows. With this connector, you can monitor the device, **change its configuration** where possible, and **restore a configuration** when needed, all from within DataMiner.

The connector organizes the device data into clear tree views and tables for input and output transport streams, video and audio properties, and the physical network setup, so you can navigate a complex device quickly and reliably.

## Key Features

- **Monitor** the full device configuration, including cards, transport streams, and temperatures, through structured tree views and tables.
- **Configure** input, output, video, audio, and network settings directly from DataMiner.
- **Back up and restore** device configurations, both to a file and to the device internal memory.
- **Manage** input and output transport streams, services, and components across the signal chain.
- **Track** active alarms with a dedicated current-alarms overview.
