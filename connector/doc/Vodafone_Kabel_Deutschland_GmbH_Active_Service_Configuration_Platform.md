# Vodafone Kabel Deutschland GmbH Active Service Configuration Platform

## About

The Vodafone Kabel Deutschland GmbH Active Service Configuration Platform connector collects active service configurations from enhanced services throughout the DataMiner System. Entries are identified by use case, such as Pre-Encoding, Satellite Downlink, or IP Gateway.

## Key Features

- **Centralized service view**: Collect active configurations from enhanced services.
- **Use case identification**: Distinguish configurations by their associated service use case.
- **Configurable discovery**: Set discovery and heartbeat intervals for service discovery and data collection.

## Use Cases

### Reviewing Configurations Across Service Types

**Challenge**: Different service types expose their active configurations through separate enhanced services.

**Solution**: The connector consolidates these configurations and identifies each entry by use case.

**Benefit**: You can review active configurations across service types from a single overview.
