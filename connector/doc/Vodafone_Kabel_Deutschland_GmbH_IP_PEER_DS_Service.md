# Vodafone Kabel Deutschland GmbH IP PEER DS Service

## About

The Vodafone Kabel Deutschland GmbH IP PEER DS Service connector monitors the active configuration of IP Peering DCM and connected XSwitch elements per service.

This connector is an enhanced service connector designed for a specific project and is not intended for general reuse.

## Key Features

- **Peering Configuration**: Monitor IP Peering DCM and connected XSwitch elements in the service.
- **Site-Level Status**: View active stream states per site.
- **Service Diagnostics**: Retrieve active alarms and enable debug logging for included elements.

## Use Cases

### Monitoring IP PEER DS Services

**Challenge**: A peering service includes DCM and connected XSwitch elements that need to be monitored together.

**Solution**: The connector monitors their active configuration and presents site-level stream states and related alarms.

**Benefit**: You can investigate service issues with visibility into both peering and switch elements.
