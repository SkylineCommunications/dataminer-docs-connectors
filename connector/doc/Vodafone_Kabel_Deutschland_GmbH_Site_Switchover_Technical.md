# Vodafone Kabel Deutschland GmbH Site Switchover

## About

The Vodafone Kabel Deutschland GmbH Site Switchover connector monitors and retrieves KPIs related to active downlink streams. It supports Satellite Downlink, Pre-Encoding, and IP Gateway use cases.

## Configuration

### Prerequisites

This connector requires [CISCO DCM](xref:Connector_help_CISCO_DCM) 1.0.3.47 or later.

### Connections

#### Virtual Connection

This connector uses a virtual connection and does not require any input during element creation.

## How to Use

The **General** page displays the **DCM Devices Table**, which lists all DCM devices that are being polled. You can perform several actions on this table via its right-click menu.
