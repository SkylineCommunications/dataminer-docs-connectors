# Norsat 1:1 LNB Redundant Controller

## About

The **Norsat 1:1 LNB Redundant Controller** is a redundancy management system designed to monitor and control LNB equipment in satellite reception environments. It provides visibility into the active and standby LNB devices, operating configuration, and current measurements.

The system supports management of active and standby LNB devices, monitoring of LNB operating conditions, and configuration of current warning and fault thresholds. This helps operators identify abnormal LNB conditions and manage redundancy from a centralized interface.

With dedicated views for device status, LNB measurements, configuration, and alarms, the connector provides a clear operational interface for monitoring and managing the Norsat 1:1 LNB redundant controller.

## Key Features

* **LNB redundancy management**: Monitor active and standby LNB devices and select the active device when required.
* **LNB operating monitoring**: Monitor LNB frequency band and current measurements for connected LNBs.
* **Configurable protection thresholds**: Define minimum and maximum current warning and fault thresholds.
* **Flexible device configuration**: Configure ULC status and the number of supported multiband LNB bands.
* **Alarm and status monitoring**: View active LNB faults and warnings to help identify abnormal operating conditions.
