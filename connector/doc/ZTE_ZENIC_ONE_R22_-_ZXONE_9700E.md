# ZTE ZENIC ONE R22 ZXONE 9700E

## About

The ZTE ZENIC ONE R22 ZXONE 9700E connector is an exported DVE connector generated by the ZTE ZENIC ONE R22 parent connector.

It provides node-centric monitoring for discovered ZXONE 9700E managed elements, including optical metrics, alarm information, and hardware status views.

## Key Features

- Exported DVE per discovered node from the parent connector.
- Monitoring of node optical and interface metrics.
- Monitoring of directional optical ports and OAC ports.
- Monitoring of slot, fan, and termination point status.
- Monitoring of current and consolidated alarm information.

## Prerequisites

- DataMiner version **Main Release** 10.4.0 or higher.
- A configured and operational parent connector element of **ZTE ZENIC ONE R22**.
- Discovered node entries in the parent connector node inventory.
