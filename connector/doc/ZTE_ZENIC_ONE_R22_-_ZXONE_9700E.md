# ZTE ZENIC ONE R22 - ZXONE 9700E

## About

The ZTE ZENIC ONE R22 ZXONE 9700E connector is an exported DVE connector generated by the [ZTE ZENIC ONE R22](xref:Connector_help_ZTE_ZENIC_ONE_R22) parent connector.

It provides node-centric monitoring for discovered ZXONE 9700E managed elements, including optical metrics, alarm information, and hardware status views.

## Key Features

- **Access node DVEs**: Open the exported DVE for each discovered node from the parent connector.
- **Track node performance**: View node optical and interface metrics.
- **Monitor optical ports**: View directional optical ports and OAC ports.
- **Check hardware status**: View slot, fan, and termination point status.
- **Review alarms**: View current and consolidated alarm information.

## Prerequisites

- DataMiner **Main Release 10.4.0** or higher.
