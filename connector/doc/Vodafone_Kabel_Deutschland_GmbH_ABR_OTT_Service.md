# Vodafone Kabel Deutschland GmbH ABR OTT Service

## About

The Vodafone Kabel Deutschland GmbH ABR OTT Service connector monitors the active configuration and streaming status of Harmonic VOS/XOS elements per service.

This connector is an enhanced service connector designed for a specific project and is not intended for general reuse.

## Key Features

- **Streaming status**: View active stream states per site for the included OTT services.
- **Configuration visibility**: Inspect the active configuration of input and output devices.
- **Service diagnostics**: Retrieve active alarms and enable debug logging for included services and elements.

## Use Cases

### Monitoring OTT Service Delivery

**Challenge**: OTT services span encoder elements whose configuration and stream states need to be checked together.

**Solution**: The connector brings Harmonic VOS/XOS configuration, site-level streaming states, and service alarms into one enhanced service.

**Benefit**: You can investigate OTT service issues with the relevant device configuration and alarms available together.
