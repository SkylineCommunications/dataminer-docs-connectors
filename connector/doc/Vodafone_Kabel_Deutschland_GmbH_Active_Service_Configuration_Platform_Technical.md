# Vodafone Kabel Deutschland GmbH Active Service Configuration Platform

## About

The Vodafone Kabel Deutschland GmbH Active Service Configuration Platform connector collects active service configurations from enhanced services throughout the DataMiner System. Entries are identified by use case, such as Pre-Encoding, Satellite Downlink, or IP Gateway.

## Configuration

### Connections

#### Virtual Connection

This connector uses a virtual connection and does not require any input during element creation.

## How to Use

You can find all the information you need to monitor on the **General** page.

On the **Configuration** page of this connector, you can configure the discovery and heartbeat intervals. The **discovery interval** determines how frequently the connector will search for new enhanced services. The **heartbeat interval** determines how frequently the connector will collect the data from the enhanced services.
