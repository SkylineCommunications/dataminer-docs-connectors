# Vodafone Kabel Deutschland GmbH Site Switchover

## About

The Vodafone Kabel Deutschland GmbH Site Switchover connector monitors and retrieves KPIs related to active downlink streams. It supports Satellite Downlink, Pre-Encoding, and IP Gateway use cases.

## Key Features

- **Downlink KPIs**: Retrieve monitoring information related to active downlink streams.
- **Multiple Use Cases**: Support Satellite Downlink, Pre-Encoding, and IP Gateway monitoring.
- **DCM Device Overview**: View polled DCM devices and access table actions.

## Use Cases

### Reviewing Active Downlink Monitoring Data

**Challenge**: Active downlink streams span multiple use cases and DCM devices.

**Solution**: The connector retrieves relevant KPIs and lists the DCM devices being polled.

**Benefit**: You can review downlink monitoring information and access device table actions from DataMiner.
