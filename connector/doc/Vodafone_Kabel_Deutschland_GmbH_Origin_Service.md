# Vodafone Kabel Deutschland GmbH Origin Service

## About

The Vodafone Kabel Deutschland GmbH Origin Service connector provides an enhanced service overview for Origin services. It brings together service metadata, the status of included elements, and active alarms.

The connector shares aggregated service information with the [Active Service Configuration Platform](xref:Connector_help_Vodafone_Kabel_Deutschland_GmbH_Active_Service_Configuration_Platform).

## Key Features

- **Service metadata**: View the service lifecycle, service CID, tenant, and reservation GUID.
- **Element status**: Review the state, alarm severity, and alarm counts of elements included in the service.
- **Alarm monitoring**: Enable active alarm monitoring to inspect alarms associated with the service.
- **Configuration sharing**: Share aggregated service information with subscribed Active Service Configuration Platform elements.
- **Service diagnostics**: Enable debug logging to investigate service monitoring and data retrieval.

## Use Cases

### Monitoring Origin Services

**Challenge**: Origin service metadata, element status, and alarms need to be reviewed together to understand the service.

**Solution**: The connector presents this information in an enhanced service and shares its aggregated configuration with the Active Service Configuration Platform.

**Benefit**: You can investigate Origin service issues using a dedicated overview while keeping service information available for centralized configuration monitoring.
