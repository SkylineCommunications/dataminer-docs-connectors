# Telenor Agama OTT Status

## About

This connector retrieves alerts from Grafana that were generated by Agama analyzers and makes them available in DataMiner for monitoring.

## Key Features

- **Agama Alerts**: All the details of the alerts are displayed, including the start time, severity, country, asset, etc.
