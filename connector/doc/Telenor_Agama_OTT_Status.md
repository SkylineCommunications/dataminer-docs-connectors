# Telenor Agama OTT Status

## About

This connector is used to connect to a Grafana server and retrieve the alerts that were pushed by the Agama analyzers.

## Key Features

- **List Agama Alerts**: All the details of the alerts are displayed (Start time, Severity, Country, Asset,...)
