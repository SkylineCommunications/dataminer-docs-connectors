# Telenor Agama OTT Status

## About

This connector retrieves from Grafana the alerts generated by Agama analyzers and makes them available in DataMiner for monitoring.

## Key Features

- **List Agama Alerts**: All the details of the alerts are displayed (Start time, Severity, Country, Asset,...)
