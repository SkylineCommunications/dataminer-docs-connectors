# Vodafone Kabel Deutschland GmbH Channel Management

## About

The Vodafone Kabel Deutschland GmbH Channel Management connector retrieves and displays channel and service data from a DataMiner Object Models (DOM) database. If the database does not yet exist, the connector creates it.

## Key Features

- **Channel and Service Visibility**: Display the Channels and Services tables from the DOM database.
- **Database Initialization**: Create the database if it does not already exist.
- **Data Refresh**: Refresh table data periodically or request a refresh manually.

## Use Cases

### Keeping Channel and Service Data Accessible

**Challenge**: Channel and service information stored in DOM needs to be available for operational review.

**Solution**: The connector displays the database tables and refreshes their contents, with a manual refresh option.

**Benefit**: You can consult recent channel and service data directly in the element.
