# Vodafone Kabel Deutschland GmbH UDP-RTP GW Service

## About

The Vodafone Kabel Deutschland GmbH UDP-RTP GW Service connector monitors the streaming states of ProStream X multiplexers included in an enhanced service.

## Key Features

- **Multiplexer monitoring**: Monitor the streaming states of included ProStream X multiplexers.
- **Site-level status**: View active stream states per site.
- **Service diagnostics**: Retrieve active alarms and enable debug logging.

## Use Cases

### Monitoring UDP-RTP Gateway Services

**Challenge**: ProStream X streaming states need to be reviewed in the context of the gateway service.

**Solution**: The connector presents site-level streaming states with access to alarms for included services and elements.

**Benefit**: You can investigate gateway stream issues from a dedicated service overview.
