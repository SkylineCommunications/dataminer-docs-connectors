# Vodafone Kabel Deutschland GmbH RegioMUX Lineup Service

## About

The Vodafone Kabel Deutschland GmbH RegioMUX Lineup Service connector monitors the regional lineup of ProStream X devices per site.

This connector is an enhanced service connector designed for a specific project and is not intended for general reuse.

## Key Features

- **Regional lineup monitoring**: Monitor the regional lineup of ProStream X devices.
- **Site-level status**: View active stream states per site.
- **Service diagnostics**: Retrieve active alarms and enable debug logging.

## Use Cases

### Monitoring Regional Multiplex Lineups

**Challenge**: Regional lineups need to be monitored across the sites hosting ProStream X devices.

**Solution**: The connector provides a service-level view of the regional lineup and site streaming states.

**Benefit**: You can assess regional service status and consult related alarms in one place.
